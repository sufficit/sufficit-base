# Identidade DID de entrada

InboundDid define o parâmetro did, normalização de números completos brasileiros
e identificadores internos 00, extração estrita para migração e comparação com
histórico formatado. Não concatenar números ambíguos. Preservar Key/Extra históricos.
Validação nos consumidores: InboundDidTests (EFData), projeções de telefonia e
ServicesBalance (Blazor). A publicação global da exigência depende da conciliação
dos contratos sem identidade; não foi declarado deploy por este commit.
