# Correção da identidade Flexível+

Compartilhado equivale ao Flexível+ (4 canais, 450 tentativas admitidas/72h), não ao Flexível novo (210/72h). Correção autorizada pelo mantenedor; preservar preço e exceções operacionais SINGLE. Identidade do catálogo legado permanece, histórico das renomeações anteriores continua válido. A família pode ser usada para exclusividade, mas o nome Flex genuíno não é normalizado para Plus sem a identidade legada.

Validação local conjunta: 80 testes EFData; 33 testes adicionais de replay/renomeação incluindo a cadeia Compartilhado → Flex → Flex+ (suítes sobrepostas); 27 Standard; 193 API. Standard netstandard2.0 e Blazor compilados sem erros. Publicação e corte de dados registrados no plano do Endpoints; este registro não prova implantação.
