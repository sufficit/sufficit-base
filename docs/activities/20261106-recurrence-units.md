# Recurrence units

Implemented quantity + Days/Months independent of recurrence and settlement. Existing monthly schedules and issued evidence are preserved. Additive nullable catalog schema and audited contract parameters. Daily cycles are never submitted as monthly recurring card authorizations; specialized resource grants retain their dedicated workflow.

Validation so far: 632 Sales backend tests passed (one MySQL integration skipped), 117 Blazor service tests passed, 226 API tests passed against actual candidate runtime libraries (CustomerSearch, InternalPermission, BillingCheckout, Voice, CallCredit, Representative, Cadence). Browser verified quantity 15 and Days/Months switching at 1440/768/390; tablet screenshot inspected. Fixed numeric readonly attribute discovered during browser validation. Deployment pending.
