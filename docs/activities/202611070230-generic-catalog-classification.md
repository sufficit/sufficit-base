# Classificação genérica de catálogo

Configuração de adaptadores por tipo de serviço via IntegrationBindings. Runtime de telefonia passa a ler o catálogo/evento, não inbound_kind do contrato. Produto pai propagado na cobertura para preservar o escopo de modalidades. Reclassificação comercial genérica com histórico/recibo/revisão, sem recálculo financeiro. Editor preserva vínculos durante edição.

Validações em andamento; migração de produção ainda não aplicada. Ver plano em sufficit-efdata/docs/PLAN-GENERIC-CATALOG-CLASSIFICATION.md. Evidências operacionais privadas em tmp/catalog-classification; nenhum segredo versionado.
